One smug line from a judgmental self-checkout machine, aimed at a shopper whose whole basket is twelve yoghurts. The program drafts fourteen original one-liners, grades each one against the brief, and keeps only the strongest for the entry file.
> Twelve yoghurts. No spoon, no shame, no meal. Please place your dignity in the bagging area.
## Try it
Run `python3 main.py` — it prints the winning line and writes `entry.txt` under `/output/`.
